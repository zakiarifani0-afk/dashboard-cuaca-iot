SUHU CELCIUS

Celcius (°C)

Termistor NTC (Sensor)

1/T = 1/T₀ + 1/B * ln(R/R₀)
T = Suhu Kelvin (Dikonversi ke °C)
T₀ = Suhu Ruangan Referensi
B = Konstanta Material NTC
R = Resistansi Sensor Saat Ini
R₀ = Resistansi Referensi

SUHU FAHRENHEIT

0
Fahrenheit (°F)

Konversi Celcius ke Fahrenheit

F = (C * 1.8) + 32
F = Nilai Suhu Fahrenheit
C = Nilai Suhu Celcius
1.8 = Rasio skala (9/5)
32 = Titik beku air pada Fahrenheit

SUHU REAMUR

0
Reamur (°R)

Konversi Celcius ke Reamur

R = C * 0.8
R = Nilai Suhu Reamur
C = Nilai Suhu Celcius
0.8 = Rasio skala (4/5)

SUHU KELVIN

0
Kelvin (K)

Konversi Celcius ke Kelvin

K = C + 273.15
K = Nilai Suhu Kelvin (Suhu Mutlak)
C = Nilai Suhu Celcius
273.15 = Titik nol mutlak pada skala Celcius

Persentase (%)

Sensor Kapasitif Internal

C = C₀ * (1 + α(RH - RH₀))
C = Kapasitansi yang diukur
